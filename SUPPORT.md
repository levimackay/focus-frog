# Support

Focus Frog is a young, actively-developed project maintained in spare time.
There's no paid support tier and no guaranteed response time.

## Where to get help

- **Bug reports and feature requests**: open a GitHub Issue on this
  repository. Include your OS/version, what you expected, and what actually
  happened — for activity-detection issues, mention whether it's macOS,
  Windows, or Linux (and X11 vs Wayland on Linux), since that code path is
  the most platform-sensitive part of the app.
- **Questions and general discussion**: use GitHub Discussions on this
  repository if it's enabled; otherwise, open an Issue and tag it as a
  question.
- **Security vulnerabilities**: do not open a public issue — see
  [SECURITY.md](SECURITY.md) for the private reporting path.

## Out of scope

- Requests to remove the privacy/local-first design, add telemetry, or add a
  cloud sync/account system as a default behavior — these run against the
  project's core design (see [PRIVACY.md](PRIVACY.md)). A well-argued,
  opt-in proposal is a different conversation; silently changing the default
  is not on the table.
- General Rust, React, or Tauri tutoring unrelated to this codebase — the
  [Tauri docs](https://v2.tauri.app/) and each library's own community are a
  better fit for that.
- Support for building/running this on mobile targets — Focus Frog currently
  targets desktop (macOS/Windows/Linux) only.
